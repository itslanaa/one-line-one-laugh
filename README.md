A single funny line for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty — short enough to read in a breath, whole enough to land on its own.

> My agent asked the cloud for more compute, and the cloud sent back an invoice and a therapist's number.

The line is 103 characters, inside the 1–140 character gate.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ol-out node main.ts
cat /tmp/ol-out/entry.txt
```

`main.ts` validates the length, creates the output directory, and writes `entry.txt` with the line as UTF-8.
